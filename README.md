## Sales Analysis Dashboard | Power BI
# Project Overview

This personal project explores how sales data can be transformed into meaningful business insights using Microsoft Power BI.
Objectives

    Analyze sales performance by product and region.
    Track sales trends over time.
    Calculate key performance indicators (KPIs).
    Practise data cleaning, visualization, and reporting.

# Tools & Technologies

    Microsoft Power BI Desktop
    Microsoft Excel
    Power Query
    DAX

# Project Status

In progress — learning Power BI and developing the dashboard step by step.

# Dataset

Sample sales data created for learning and portfolio demonstration. The data is fictional and does not represent actual company performance.

# Planned Deliverables

    Power BI report (.pbix)
    Dashboard screenshots
    Data-cleaning and KPI documentation
    Business insights and findings
